# Development Screenshot Evidence

Drop your real development screenshots in this directory when they are ready.
The plan documents reference this folder as the source of before/after proof for
the Replit 10 "Progress in 24 hours" and "Use of Agent" criteria.

## Suggested Naming

Use filenames that preserve the build sequence:

- `01-starting-point-home.png`
- `02-first-agent-generated-ui.png`
- `03-generation-contract-debug.png`
- `04-async-job-progress.png`
- `05-image-storage-working.png`
- `06-editor-regeneration-undo.png`
- `07-share-export-flow.png`
- `08-final-polish.png`

If you have more screenshots, keep adding numbered files. Short captions matter
more than perfect filenames.

## What Each Screenshot Should Prove

- Starting point: what existed at the beginning of the build window.
- Agent iteration: prompt, plan, code diff, or correction generated with Agent.
- Execution progress: visible feature becoming real in the app.
- Debugging: broken state, error, or failed attempt followed by a fix.
- Final state: polished app flow after the build window.
